# 工程画布放置规范

1. 调用 `GET /api/projects/{id}/flow`，读取当前节点、连线、`revision` 和 `layout`。以 `layout` 提供的网格间距、节点尺寸和坐标上限为准。
2. 原点是画布左上角。节点的 `x`、`y` 表示卡片左上角距原点的水平和垂直距离，单位是未缩放的画布像素。根据已有节点的 `x` 或 `y` 延续行列。通过 `floor((坐标 + 网格间距 / 2) / 网格间距) × 网格间距` 吸附到最近的交点。例如网格间距为 `16` 时，`(302, 101)` 对齐为 `(304, 96)`。浏览器画面上的位置需要先扣除画布原点在屏幕上的位置，再除以当前显示比例。
3. 保留不涉及本次编辑的节点及其坐标。同一列复用 `x`，同一行复用 `y`。开辟新行列时按节点尺寸检查矩形占用，并给卡片和连线留出间距。当前节点尺寸为 `198 × 76`，画布自动放置使用 `272` 的列距和 `112` 的行距。局部新增优先沿用该区域现有的间距。
4. 通过 `POST /api/projects/{id}/flow` 提交原 `revision`、完整 `nodes` 和 `edges`，并保留已有的 `relation_scope`。服务端将新增节点和坐标有改动的节点吸附到网格，并拦截对齐后引入的卡片重叠。以响应返回的坐标和 `revision` 为准。收到版本冲突时，重新读取画布并在最新版本上应用本次编辑。

拖动卡片靠近网格上已有节点的行或列时会显示对齐参考线。重叠位置在拖动中标红，松手后卡片回到原位。旧画布可在工具栏通过「对齐网格」预览整体对齐结果，再按需保存。

外部 MCP 客户端可用 `ws_agent_guideline` 读取工作区的完整流程规范，用 `ws_get_project_flow` 读取画布和关系依据，用 `ws_save_project_flow` 保存。MCP 保存受工作台「设置 → 外部接入」的写入授权约束。工具参数见 [MCP 手册](../mcp/README.md#绘制工程画布)。
