# 科研工作台功能体验与舒适度反馈

体验日期：2026-10-20，Asia/Shanghai。

当前工作台已经能串起项目、文献、知识笔记和 Agent；可追溯检索、中断、编辑重发、草稿确认等环节也有回归保障。下一步最值得投入的是阅读空间、状态解释和日常操作层级。增加功能之前，应先让这些已有能力更容易理解和使用。

## 本次已经完成

- 清除向量索引必须经过弹窗确认。弹窗显示当前来源数和分块数，说明自动更新将关闭、原始资料和记忆会保留，以及重建索引可能产生嵌入费用。
- 默认聚焦“取消”；点击取消、按 Escape 或点击遮罩均不发送清除请求。取消后焦点回到原按钮；接口失败时显示错误并允许重试。确认框未加载时拒绝执行。
- 对话标题栏取消整条突出的底色，增加轻量图标和“当前对话”层级；引用入口缩为“引用资料”，删除改为带说明的图标按钮。长标题省略显示并保留完整悬停标题，窄屏不挤压操作按钮。
- 将“未引用本地知识”改为“未手动引用资料”，说明手动附加资料与自动 RAG 检索的区别。

## 体验与验证范围

实际页面使用本地现有数据，在独立检查页完成，保留用户原有设置页。查看了概览、项目、待办、专注、笔记列表及阅读模式、文献列表、种子论文 PDF、知识图谱，以及 Agent 对话、执行记录、记忆、技能和 RAG 设置。

实库在体验期间正在构建索引，构建和清除按钮按状态禁用。没有点击实库的清除、取消构建、连接测试、语义检索或更新，也没有发送真实模型请求。清除、保存、同步冲突等写操作通过临时工作区或模拟服务验证。

## 优先建议

| 优先级 | 实际感受与触发位置 | 建议 |
| --- | --- | --- |
| 优先处理 | 笔记默认同时展示元数据、工具栏和分屏编辑。在 1280 × 720 下，正文能直接看到的区域偏小。文献元数据更多，初次进入主要看见表单。 | 打开已有资料时优先进入阅读模式；元数据默认显示标题、项目、阅读状态，其余收进“资料信息”。编辑时再展开编辑工具。保留用户最后使用的模式。 |
| 优先处理 | PDF 工作区左侧文献列表、右侧信息栏同时占位，中央论文在当前缩放下需要横向移动，工具栏也拥挤。 | 默认适应可用宽度；提供明确的“专注阅读”入口，一次收起左右栏。右侧尚无内容时自动收起；选择文字后再突出批注和 AI 动作。 |
| 优先处理 | 输入区的总开关与历史回复的有效权限可能不同。“只参考 RAG”时，历史记录中的 Skill 和记忆关闭，但默认开关仍可亮起。 | 将输入区标为“默认能力”，历史记录标为“本次生效”。遇到任务限定时显示简短原因，例如“按你的要求，本次仅使用 RAG”。不要用当前开关去覆盖历史事实。 |
| 优先处理 | 切换页面时，页标题先改变，原页面内容可能短暂保留到新数据返回。 | 进入目标页时立即显示对应加载占位，避免“新标题配旧内容”；失败时保留明确的重试入口。 |
| 随后处理 | Agent 任务列表以 `run-…` 为主标题，时间使用原始格式；详情又完整重复对话回答，查找任务费力。 | 用“用户问题摘要 + 状态 + 易读时间”命名。列表直接标出“等待你确认”；详情优先展示步骤、待处理草稿和结果入口，内部编号与原始事件放入诊断折叠区。 |
| 随后处理 | RAG 页面同时包含接口、分块、更新、构建、清除和检索试用。构建期间“尚未建立”与构建进度分散显示，容易误判。 | 顶部先给一张状态卡：“关键词可用 / 语义索引构建中 / 可用 / 配置已变化”。常用操作仅保留“连接检查”和“更新资料”；分块参数、自动更新、清除置于各自折叠区。构建进度靠近状态卡。 |
| 随后处理 | 知识库有大量真实题录和摘要，但“待阅读 / 阅读中”不能完整表达证据覆盖程度。检索依据虽然显示片段，仍需读正文才能判断资料范围。 | 将“题录 / 公开摘要 / 有 PDF 全文 / 已核对原文”作为独立证据标签。检索卡片与文献列表共用标签；有 PDF 时提供“查看原文”与“查看笔记”两个明确入口。 |
| 随后处理 | 图谱初始展示大量节点和关系，标签重叠；页面展示 Force、LOD、布局毫秒等信息，暗色概况卡仍有明显亮色块。 | 默认按当前项目或选中主题展示一到两级关系，再允许扩展全图。技术指标移入诊断；暗色概况卡使用同一套背景、文字与边框色。 |
| 随后处理 | 两个项目都使用完整论文题目，符合项目命名要求，但在筛选下拉框、标签和窄列表中很难区分。 | 保留正式名称，增加可选“显示简称”，只用于导航与标签，悬停显示全文。项目统计说明同一资料可属于多个项目，避免把分项目数量相加当作总量。 |
| 随后处理 | 记忆管理需要手填项目标识，空结果时缺少用途示例；技能页同时展示名称、技术目录和导入方式。 | 记忆改用项目名称选择器；空状态给“记录研究偏好”等示例。技能列表先展示用途、启用状态和最近使用情况，资源路径与脚本环境进入详情。 |
| 可后续优化 | 概览首屏有热力图、学业进度和多组统计，而当前文献阅读与检索任务需要继续操作。 | 增加“继续上次工作”：最近 PDF、未确认草稿、最近 Agent 对话。统计卡可折叠或调整顺序，允许用户按研究阶段选择重点。 |
| 可后续优化 | 次要文字较小，应用缩放、编辑缩放和预览缩放同时存在；窄屏下会话列表与多层导航也占据高度。 | 提供统一阅读字号入口，说明各缩放的作用。窄屏将会话列表收为抽屉，优先保留消息区和输入框；常用图标补充悬停与键盘提示。 |

## 建议实施顺序

先处理“笔记 / PDF 阅读空间”和“默认能力 / 本次生效”的解释，再整理任务列表与 RAG 状态卡；之后改善资料的证据标签和图谱聚焦，最后调整概览与窄屏布局。每轮只改一个主要使用流程，用固定的长标题、长回答、空结果和失败场景复核，避免为了验证界面再次调用模型。

建议保留已有的优点：Agent 主页面与悬浮助手共享会话，长回答可追溯检索来源，历史问题编辑后保留原记录，危险操作有取消路径，后台索引构建时阻止并行清除。这些能力能减少重复操作和误操作。
